# HR Analytics Dashboard
## Project Overview
This project focuses on analyzing employee data using Microsoft Power BI to understand workforce distribution, employee attrition, salary trends and employee satisfaction.
## Tools Used
- Microsoft Power BI
- Power Query
- DAX
## Dashboard Pages
1. Home
2. HR Overview
3. Department Analysis
4. Salary & Employee Satisfaction
5. Employee Attrition
## Key Performance Indicators
- Total Employees
- Active Employees
- Employees Left
- Attrition Rate
- Average Employee Age
- Average Monthly Income
## Key Analysis
- Department-wise employee distribution
- Employee distribution by age group and job role
- Employee attrition by gender and overtime
- Salary analysis by department
- Employee satisfaction and work-life balance
## Skills Demonstrated
- Data Cleaning
- Data Transformation
- DAX Measures
- Data Visualization
- Dashboard Development
- HR Data Analysis
## Project Objective
To analyze HR data and provide meaningful insights into workforce trends and employee attrition.
